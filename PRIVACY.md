# Конфиденциальность

Traverce не собирает телеметрию, не требует аккаунта и не отправляет настройки разработчику.

Что приложение хранит локально в `%LOCALAPPDATA%\Traverce`:

- `settings.json` — включённые сервисы, настройки запуска и секрет локального Telegram-прокси;
- память выбранных zapret2-стратегий для разных сетей;
- `traverce.log` — технический журнал для диагностики.

Что уходит в сеть:

- обычный трафик сервисов, которыми вы пользуетесь;
- DNS-запросы выбранных Smart DNS-сервисов — только для доменов, перечисленных в каталоге Traverce;
- короткие HTTPS/DNS-проверки доступности, когда Traverce проверяет состояние сервисов;
- Telegram-трафик при включённом локальном Telegram-прокси.

Traverce не расшифровывает HTTPS-трафик и не устанавливает собственные корневые сертификаты.

При удалении через Setup удаляются программа, задача автозапуска, NRPT-правила, созданные Traverce, и локальные данные из `%LOCALAPPDATA%\Traverce`. Для пользователей, обновившихся с 0.2, uninstall также очищает legacy state `%LOCALAPPDATA%\Prosvet`.
